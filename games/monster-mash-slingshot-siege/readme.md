## Source description

A fast, tactile 16-bit physics launcher built in Phaser 3, Matter.js, and TypeScript for the RUN.world Monster Mash game jam. Runs portrait at native 216x384 (retro Mash32 palette, 5x7 typography, and custom chiptune audio). Commit carries an exact Claude Opus 5.5 / Claude Sonnet 5.5 co-author trailer. Source inspected from README, file tree and commit history only; no playtest.
