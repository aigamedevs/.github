A portrait-mode 3D endless motorcycle arcade game built with Flutter and the Flame game engine. It is a fictional, humorous game set on Philippine-inspired highways. All characters, officers, vehicles and brands in it are made up. Commit carries an exact Claude Opus 5.5 co-author trailer.
