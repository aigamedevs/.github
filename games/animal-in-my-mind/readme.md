## Source description

An iPad-first web app for the guessing game "Animal in My Mind", and a fact-learning app for a young reader. Every answer is meant to be technically correct, including the surprising ones (moose swim, platypuses lay eggs). No backend, no accounts, no external… Commit carries an exact Claude Opus 5.5 co-author trailer. Source inspected from README, file tree and commit history only; no playtest.
