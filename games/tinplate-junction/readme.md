## Source description

A 3D tabletop toy train layout that runs in the browser. Lay O27 tubular three-rail track on an 8 × 5 ft table, couple up a 1960s-style train and run it from a bakelite transformer. Built on three.js, with no npm dependencies. Commit carries an exact Claude Opus 5.5 co-author trailer. Source inspected from README, file tree and commit history only; no playtest.
