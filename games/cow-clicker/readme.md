## Source description

A tiny browser cow clicker inspired by the one in Fears to Fathom: Scratch Creek. Click the cow, buy barn upgrades, and try to reach 100,000,000 clicks. Progress is saved in your browser. Commit carries an exact Claude Opus 5.5 co-author trailer. Source inspected from README, file tree and commit history only; no playtest.
