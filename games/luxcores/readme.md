## Source description

A mobile strategy game where every unit and building is made of light. Defend your Lumen Core, build collectors and towers, send creep groups down three curved lanes, and lead one hero at a time from a roster of five. Commit carries an exact Claude Sonnet 5.5 co-author trailer. Source inspected from README, file tree and commit history only; no playtest.
