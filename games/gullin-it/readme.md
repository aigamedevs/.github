## Source description

A six-level, data-driven seaside arcade prototype for Godot. Aim a gull, hold climb, and dive to steal food while avoiding defensive beachgoers and competing gulls. Tested with the local Godot 4.7.2 Windows build. Commit carries an exact Claude Opus 5.5 / Claude Sonnet 5.5 co-author trailer. Source inspected from README, file tree and commit history only; no playtest.
